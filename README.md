# medias
Visuels publies par Le Lobby (@lelobbyactu).

- `PIPELINE.md` : consignes des taches automatiques (veille, selection, montage, publication)
- `scripts/make_reel.py` : montage d un reel clip + gros titre
- `scripts/make_carousel.py` : rendu d un carrousel d actu depuis une spec JSON (exemple : `scripts/exemple_carousel.json`)
- `assets/keyart/` : visuels officiels des jeux (fonds de cover)
- `state/published.json` : journal des posts
- `state/queue.json` + `queue/` : file d attente des sujets reperes par la veille (medias telecharges)
